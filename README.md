# Questify Learning

Build a gamified K-12 learning platform website called 'LearnQuest' (or suggest a better original name), combining the structure of an EdTech platform like BYJU'S with the gamification style of Duolingo. Include:

- A hero section with a friendly, colorful, playful design (not corporate) — bold headline, mascot-style illustration or icon, and a 'Start Learning' CTA.
- A grade-selector section: cards for Grade 1 through Grade 12, each leading conceptually to grade-specific content.
- A subject-selector for a chosen grade: Math, Science, English, etc., styled as colorful game-level icons (like a Duolingo skill tree — connected nodes/path showing progression through topics).
- A gamification layer: show a sample student dashboard with a streak counter (🔥 7-day streak), XP points, level badges, and a progress bar per subject.
- A leaderboard section showing top learners with avatars and points, styled like a game leaderboard.
- A rewards/badges showcase — a grid of achievement badges (e.g., 'Math Master', 'Reading Streak') with locked/unlocked states.
- A parent/teacher dashboard preview section showing progress tracking, styled clean and professional (contrast to the playful student side).
- Bright, playful color palette (greens, yellows, blues — Duolingo-inspired), rounded fonts, mascot character if possible, smooth animations on hover/click.
- Fully responsive, mobile-first since K-12 platforms are heavily used on tablets/phones.
